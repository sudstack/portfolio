Hoverplay Demo

An advanced digital media platform that bridges the physical and digital worlds by displaying video content over static photographs. The system detects reference photographs in real-time to overlay precisely aligned videos, creating an immersive "Harry Potter-style" experience. It features a scalable MERN-stack web ecosystem for creators and a robust Unity mobile application for seamless AR playback.
